## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program validates the shipped `entry.png` (PNG, 1024x1024, under 1 MiB) and writes it to `/output/entry.png`. Standard library only, no network, deterministic — two runs write identical bytes.
